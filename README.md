## 🚀 Estrutura da Arquitetura (A Trilogia Vértice)

O projeto foi dividido em três módulos independentes e complementares, simulando uma jornada completa de captação, produto (SaaS) e automação de operações de alto nível.

### 🏢 Vértice 1: A Âncora Institucional & Simulador (Landing Page)
* **Objetivo:** Interface premium voltada para atração de clientes corporativos e conversão de contratos.
* **Funcionalidade:** Apresenta a marca e integra um **Simulador Estratégico Interativo** que calcula projeções e estimativas visuais para capturar o interesse do tomador de decisão.

### 📊 Vértice 2: DocAI Engine (Análise de Documentos SaaS)
* **Objetivo:** Demonstrar competência no tratamento, mineração de dados confidenciais e geração de relatórios estatísticos.
* **Funcionalidade:** Motor *Client-Side* que lê arquivos locais (PDFs, CSVs, Imagens) diretamente no navegador do usuário. 
* **Diferencial:** Possui uma **Calculadora Estatística Corporativa** que computa faturamento total, médias mensais e porcentagem de crescimento líquido, redesenhando os gráficos de linha dinamicamente e emitindo um parecer técnico textual automatizado com recomendações de consultoria baseadas na performance dos números identificados.

### 🤖 Vértice 3: AI Orchestrator (Agentes Autônomos de Decisão)
* **Objetivo:** Representar a fronteira tecnológica atual do mercado através de fluxos de trabalho inteligentes (*AI Agents*).
* **Funcionalidade:** Central de comando interativa onde múltiplos agentes especialistas (Comercial, Analista e Copywriter) simulam interações assíncronas em cadeia para resolver problemas complexos de negócios.
* **Diferencial:** Integra um **Velocímetro de Performance de Tokens em Tempo Real**, onde os gráficos oscilam e geram ondas frenéticas dinâmicas de processamento a cada milissegundo enquanto a IA executa os logs de automação no terminal.

## 🛠 Pilares Técnicos e Tecnologias Empregadas

* **Core UI/UX:** HTML5, CSS3 estruturado com variáveis CSS nativas (`:root`), design focado em modo escuro (*Dark Mode premium*), fontes corporativas (*Plus Jakarta Sans* e *JetBrains Mono*) e total responsividade para dispositivos móveis.
* **Motor Gráfico:** Chart.js integrado para manipulação assíncrona de gráficos lineares dinâmicos e rosquinhas de performance.
* **Segurança e Custos (Architecture Design):** Modelo de arquitetura *Serverless/Edge* hospedado no GitHub Pages. Todo o processamento de arquivos é feito localmente na memória do navegador do cliente (*Client-Side FileReader API*), garantindo **custo zero de infraestrutura**, velocidade extrema de carregamento e compliance total com a privacidade de dados, já que nenhum documento sensível é enviado para servidores externos.
